title: "Escaping Engine Lock-In: Open Source Tech Stacks"
summary: >-
  The dominant game engines have shaped how we think about development, but they are not the only path forward. This talk explores how open-source tools can be combined into flexible pipelines, from lightweight engines to custom rendering layers and scripting environments. With examples including Godot, Electron.js and Ionic Capacitor, it examines performance, scalability, cross-platform deployment and the realities of building on open-source foundations.
